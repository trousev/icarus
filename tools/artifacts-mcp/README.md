# artifacts-mcp

MCP-сервер (stdio) для **общей библиотеки артефактов** `/artifacts`: заводит папку
с правами, читает `index.ai.md` вместо HTML и выдаёт ссылку. Без внешних
зависимостей — только Node.js.

## Что такое артефакт

Папка `/artifacts/<slug>/` в глобальной библиотеке (она монтируется в каждый
контейнер человека):

```text
/artifacts/plan-na-chetverg/
  index.md            # то, что видит человек: index.html | index.md | index.png|jpg|svg
  index.ai.md         # обязательное описание для ИИ
  images/standup.png
  .folder-acl.json    # владелец и права
  .artifact.json      # publicId, если ссылку уже просили
```

Тип определяется по index-файлу. Остальные файлы — ассеты, ссылки внутри HTML
относительные. `index.ai.md` — не для человека: заголовок H1, о чём артефакт,
что внутри, что можно менять.

## Права

`.folder-acl.json` — общий формат для любых папок, не только артефактов:

```json
{ "version": 1, "owner": "probe", "acl": { "me": "admin", "family": "read" } }
```

- `me` — владелец, `family` — все остальные;
- `read ⊂ write ⊂ admin`: write умеет читать, admin — ещё менять права, удалять
  артефакт и делать публичную ссылку;
- по умолчанию `me=admin`, `family=read`; владелец управляет своим артефактом
  всегда, даже если выставил себе `read`.

Права проверяет не только MCP: generic `folder-guard` в контейнере блокирует
`read`/`write`/`edit`/`grep`/`find`/`ls` в чужих папках, а `bash` с абсолютным путём к `/artifacts`
запрещён целиком. Поэтому новый артефакт заводят через `artifact_new`, а не
случайным `write`: иначе папки без ACL просто не существует для инструментов.

## Инструменты (5)

| Инструмент | Назначение |
|---|---|
| `artifact_new` | создать папку и `.folder-acl.json` (owner=текущий, me=admin, family=read) |
| `artifact_list` | доступные артефакты: тип, размер, владелец, твой уровень, описание, ссылки |
| `artifact_read` | `index.ai.md` + владелец/уровень + файлы + ссылки; у markdown — ещё текст |
| `artifact_link` | по умолчанию внутренняя ссылка в панели; `public: true` — публичная (admin) |
| `artifact_check` | структура: ACL, index, `index.ai.md`, лишние index-файлы |

## Запуск

```bash
node /opt/icarus/tools/artifacts-mcp/server.mjs     # stdio
```

Сервер читает переменные окружения:

| Переменная | Зачем |
|---|---|
| `ICARUS_ARTIFACTS_DIR` | корень библиотеки; по умолчанию `/artifacts` |
| `ICARUS_USER_ID` | чьи права проверять и чей это артефакт |
| `ICARUS_URL` | внешний адрес панели; из него собираются ссылки |

Сервис кладёт всё это в контейнер человека (`containerEnv`), в конфиге MCP
прописывать не надо.

## Подключение к Икару

```yaml
mcp:
  artifacts:
    command: node
    args: ['/opt/icarus/tools/artifacts-mcp/server.mjs']
    lifecycle: lazy
    hidden: true
    description: "Артефакты: общая библиотека /artifacts — страницы, документы и картинки с правами для семьи"
```

`hidden: true` убирает сервер из раздела MCP и запрещает выключать. `lifecycle: lazy`
держит инструкции вне промпта: в `AGENTS.md` едет короткий триггер, полные правила
приезжают в `instructions` после `mcp_connect`.

## История версий

У каждой папки есть скрытый git-репозиторий, но человек про него не знает: в панели —
«История» и «Вернуть». Снимки делает расширение pi (`extensions/artifact-git.ts`) после
каждого успешного `write`/`edit`, а `turn_end` добирает изменения от MCP. Служебные
`.folder-acl.json` и `.artifact.json` не версионируются; `.git` скрыт от панели,
публичных ссылок и файловых инструментов. Агенту не нужно создавать репозитории,
коммитить или трогать `.git` — это делает система.

## Ссылки

`artifact_link` без `public` отдаёт внутреннюю `/panel/artifacts?artifact=…` — её
и надо давать человеку по умолчанию. `artifact_link` с `public: true` (нужен admin)
пишет `.artifact.json`:

```json
{ "version": 1, "publicId": "случайные-18-байт", "createdAt": "…", "updatedAt": "…" }
```

Публичный адрес — `<ICARUS_URL>/a/<артефакт>/<publicId>/`. `?bare=1` — без панели,
прямой путь на index-файл — сам файл. Старые ссылки
`/a/<человек>/<workspace>/<артефакт>/<id>/` редиректят на новый адрес.

## Проверка

```bash
node tools/artifacts-mcp/test.mjs
```

Тест поднимает сервер отдельным процессом, делает настоящий `initialize` и
проверяет `artifact_new`, список, чтение, права, ссылку и структуру на временной
папке. Модель, сеть и докер не нужны.
