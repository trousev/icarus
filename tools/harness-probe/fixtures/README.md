# Фикстуры пробника

Три файла — не выдуманные формы, а настоящие прогоны Claude Code 2.1.319 против
`https://api.deepseek.com/anthropic` (модель `deepseek-chat`), снятые в песочнице
2026-11-09. Из строк убрано только служебное, формат не менялся:

- `text-run.jsonl` — `--bare`, промпт «Ответь ровно: CLEAN-OK», изолированный HOME.
  Оставлены `system:init`, дельты текста, `assistant` и `result:success`.
- `tool-run.jsonl` — тот же режим, промпт прочитать `probe.txt`; в init оставлен реальный
  список из трёх инструментов, путь `/tmp/harness-probe/run7` заменён на
  `/workspaces/talk`, чтобы фикстура не зависела от машины. Внутри — `tool_use`, `user`
  с `tool_result` и частичные `stream_event` от `--include-partial-messages`.
- `truncated-run.jsonl` — начало прогона, у которого так и не пришёл `result` (в живом
  эксперименте это был неверный ключ: CLI ушёл в ретраи, прогон снят по таймауту).
  Нужен, чтобы проверить: отсутствие `result` — ошибка, а не тихий успех.

Убрано из `text-run`/`tool-run`:

- `system:thinking_tokens` и `system:ui_invalidate` — счётчики и перерисовки, к протоколу
  отношения не имеют;
- `system:status` — служебный статус запроса.

Остальные строки (`stream_event`, `assistant`, `user`, `result`) — как пришли. В фикстурах
нет ключей: поток событий их не содержит, а stderr с предупреждением о незнакомой модели
в файлы не попал.
