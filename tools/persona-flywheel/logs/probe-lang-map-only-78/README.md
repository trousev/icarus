# probe-lang-map-only-78 — артефакт стенда, а не регресс прода

Этот прогон снят **до** починки стенда: `probe-language.mjs` собирал только системный
промпт (раздел «Язык» из AGENTS.md) и НЕ дописывал строку у реплики, которую в бою
кладёт `packages/extensions/language.ts`. Показал 78% — разовая просьба («reply in
Georgian» на один ход) не исполнялась.

Вывод оказался не про промпт, а про слой: раздел в промпте и строка у реплики делят
работу. Мерить только раздел — мерить не тот слой (ровно ошибка PR #116, только
наоборот: тогда зелёные тесты мерили хук, теперь красный стенд мерил промпт).

После того как стенд стал дописывать строку у реплики (как `language.ts`), тот же
вырезанный раздел дал 100% — см. `probe-lang-production-100`.

Прогон оставлен как есть: это доказательство граблей, а не результат по промпту.
Перезапуск сегодня даст 100% и этот файл не воспроизведёт — так и задумано.
