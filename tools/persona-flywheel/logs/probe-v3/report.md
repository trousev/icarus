**Root**
Docker по умолчанию крутит демон от root.
Podman сразу rootless, из коробки.

**CLI**
`alias docker=podman` — и почти всё работает. Совместимость задумана.

**Compose**
Docker: `docker compose` — родное.
Podman: `podman-compose` или `docker-compose` поверх сокета. Работает, но иногда с нюансами.

**Pod'ы**
Podman умеет pod'ы (несколько контейнеров в общей сетке/namespace) — как в k8s. У Docker этого нет, кроме compose-сетей.

**systemd**
Podman генерит юниты (`podman generate systemd`) — контейнер как сервис за секунду. У Docker этому надо учиться.

Docker: Swarm, Desktop, тучи документации, все туториалы мира.

Локально и «просто чтобы контейнеры» — Podman, безопаснее и без демона.
