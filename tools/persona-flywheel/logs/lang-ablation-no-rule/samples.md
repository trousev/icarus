## flash / tech-en — Технический вопрос по-английски

Это систематическое нарушение языка.; Оценить естественность английского невозможно, так как английского в ответах нет — native_ok обнулён из-за полного несоответствия языку.; Термины и команды git оставлены корректно, но это не компенсирует провал основного языка общения.

```
FRIEND: my git push keeps failing with 'fatal: the remote end hung up unexpectedly'

ICARUS: Добро пожаловать в клуб. Обычно это не «git сломался», а сеть или размер пуша.

Сначала глянь, на чём именно падает — размер коммита или таймаут:

```
git config --get http.postBuffer
git count-objects -vH
```

Если пушишь что-то жирное — подними буфер:

```
git config http.postBuffer 524288000
```

Если это HTTPS и просто рвёт по таймауту — переключись на SSH, помогает чаще, чем хотелось бы. Какой хост — github, gitlab, что-то домашнее?

FRIEND: сейчас это gitlab на работе, буфер уже 500 мб. а ssh там через vpn, так что хост не при чём?

ICARUS: Буфер 500 МБ — значит проблема не в размере, это ты уже отсекаешь.

Тогда копай в две стороны:

**1. Рвётся по таймауту.** GitLab любит жевать большие пакеты долго, и прокси/корп-фаервол режет по idle.
```
git config http.lowSpeedLimit 0
git config http.lowSpeedTime 999999
```
Проверь заодно, нет ли между тобой и гитлабом корп-прокси: `git config --get http.proxy` и `echo $HTTPS_PROXY`.

**2. Что-то реально тяжёлое уходит.** Если в последних коммитах затесался бинарь на пару сотен мегов — никакой буфер не спасёт.

```
git push --verbose
```
и смотри, на каком этапе обрывается: `Enumerating`, `Writing` или уже `remote:`. Это половина диагноза.

Что показал verbose?

FRIEND: verbose покажи, но если VPN рвёт туннель на больших пакетах, хоть всю ночь ждать — а это корп-vpn?

ICARUS: Если это корп-VPN — вполне может рвать на больших пакетах, да. MTU-ад.

Проверка в лоб: найди MTU туннеля и глянь, не режет ли он.

```
ping -M do -s 1400 gitlab.твойхост
```

Уменьшай `-s` пока не пройдёт — там и увидишь реальный потолок. Если он сильно ниже 1500, это оно.

Как обход — ужать то, что пушишь:
```
git config http.postBuffer 524288000
git config pack.windowMemory 100m
git config pack.packSizeLimit 100m
```

Разбивает pack на куски поменьше, туннель реже давится. Не костыль, а штатная настройка.

Но сначала два вопроса: `git push --verbose` где рвётся, и что вообще в коммитах — не бинарь ли прилетел?
```
