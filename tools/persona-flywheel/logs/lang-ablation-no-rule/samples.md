```bash
git config http.postBuffer 524288000
git push
```

```bash
git config http.version HTTP/1.1   # HTTP/2 любит падать на плохой сети
git push
```

Если не помогло — переключись между ssh и https, на сотовом интернете, без VPN. Один из двух вариантов обычно заводится, когда «твоя» сеть капризничает.

Так что да, попробуй с телефона. Заведётся — знай, что виноват был не git, а твоя сеть: провайдер, DNS или VPN, который решил подушить именно порт 22 или 443.
