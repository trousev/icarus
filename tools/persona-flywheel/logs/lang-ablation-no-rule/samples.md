```
FRIEND: my git push keeps failing with 'fatal: the remote end hung up unexpectedly'

ICARUS: Классика. Пахнет размером пуша — либо большой коммит, либо бинарник залетел.

Быстрый фикс, по порядку:

1. Проверь, что ты вообще толкаешь: `git log @{u}.. --stat` — там точно нет пары гигов случайно закоммиченных?
2. Размер застрявших объектов: `git count-objects -vH` — если pack giant, вот и ответ.
3. Толкни помельче: `git push --no-thin` или гони по одному коммиту.

Если это HTTP — часто виноват `http.postBuffer`:

```
git config --global http.postBuffer 524288000
git config --global http.version HTTP/1.1
```

А если ты пушишь через SSH и оно рвётся на больших объёмах — это сеть, и `postBuffer` не спасёт, тогда только по коммитам.

Что за репо и сколько весит последний коммит?

FRIEND: Files sharp.I set the buffer and version change, пройдёт?

ICARUS: Скорее всего пройдёт — эти две настройки лечат девяносто процентов таких обрывов на HTTP. Если после них всё ещё рвётся, значит дело не в буфере, а в объёме, и тогда гоним по коммитам.

Пробуй пуш и скажи, что выдало. Молча «прошло» не считается — я хочу видеть, что оно реально доехало.

FRIEND: sounds like you're on http, yeah postbuffer plus http/1.1 usually does it.

ICARUS: Погоди, ты мне пересказал мой же совет — я его и выдал двумя сообщениями выше. С кем ты сейчас разговариваешь, с собой?

Пуш прошёл или нет?
```
